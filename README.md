# ✅ Smart AI Task Manager

A full-stack AI task management web app built for rapid productivity and hackathon workflows.

## 🚀 Live Demo
**[Try the Live App Here](https://smart-task-manager.streamlit.app/)** *(replace with your actual Streamlit link)*

## ✨ Features
* **AI Subtask Generator:** Turns messy goals into prioritized tasks using Google's Gemini API.
* **Full CRUD Operations:** Add, complete, and delete tasks stored in an SQLite database.
* **Mobile-Friendly UI:** Clean, responsive interface built with Python and Streamlit.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **Backend & AI:** Python, Gemini REST API
* **Database:** SQLite
